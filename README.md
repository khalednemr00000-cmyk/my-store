# سوق النخبة | Souq Elite - Full-Stack Modern Arabic E-Commerce Platform

متجر إلكتروني تجاري متكامل (Production-Ready) مبني بالكامل لتقديم تجربة تسوق عربية أصيلة تدعم الـ RTL بنسبة 100%، وسرعة فائقة، وهندسة برمجية معيارية قابلة للتوسع.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **واجهة المتجر والتصميم (Storefront & RTL UX)**:
   - متوافق تماماً مع القراءة العربية من اليمين لليسار (`dir="rtl"`) مع خط Cairo العربي المحسّن.
   - تصميم متجاوب (Mobile First) فائق السرعة على جميع مقاسات الشاشات.
   - صفحة رئيسية غنية بالأقسام: Hero Section, التصنيفات, المنتجات المميزة, الأكثر مبيعاً, العروض الحصرية, آراء العملاء الموثقة, والنشرة البريدية.
   - شريط بحث ذكي مع تصفية وفلترة متقدمة حسب (السعر، التصنيف، التوفر بالمخزون، والترتيب).
   - صفحة منتج غنية بمعرض صور تفاعلي (Gallery with Zoom)، محدد متغيرات (الألوان والمقاسات)، زر إضافة للسلة، وشراء فوري.
   - درج سلة مشتريات منزلق (Cart Drawer) مع شريط تتبع ذكي للحصول على الشحن المجاني.

2. **سلة الشراء وإنهاء الطلب (Cart & Checkout)**:
   - حفظ السلة محلياً عبر `Zustand` مع مزامنة ذكية ومحرك لتطبيق الكوبونات والخصومات.
   - عملية Checkout متعددة الخطوات فائقة السلاسة على الموبايل:
     - الخطوة 1: بيانات المستلم وعنوان التوصيل.
     - الخطوة 2: اختيار طريقة الشحن (عادي، سريع) وطريقة الدفع.
     - الخطوة 3: كود الخصم والمراجعة وتأكيد الطلب.
   - صفحة تأكيد وتتبع الطلب بمسار زمني مباشر (Pending -> Confirmed -> Processing -> Shipped -> Delivered).

3. **لوحة تحكم الإدارة الشاملة (Admin Dashboard)**:
   - مسارات منفصلة ومحمية بالكامل تحت مسار `/admin`.
   - لوحة إحصائيات حية: إجمالي المبيعات، عدد الطلبات، عدد العملاء، وعدد المنتجات.
   - تنبيهات فورية للمنتجات التي أوشكت على النفاد من المخزون (Low Stock Warnings).
   - إدارة كاملة للمنتجات (إضافة مع صور ومواصفات ومتغيرات وتصنيفات).
   - إدارة الطلبات: تغيير حالة الشحن، تغيير حالة الدفع، وإضافة أرقام التتبع.
   - طباعة فاتورة ضريبية رسمية مبسطة متوافقة مع هيئة الزكاة والضريبة والجمارك (ZATCA) بنقرة زر.
   - إدارة الكوبونات والعروض الترويجية (نسبة مئوية أو مبلغ ثابت، حدود دنيا، وتواريخ انتهاء).
   - إدارة العملاء والاطلاع على سجل مشترياتهم.

4. **الأمان والمصادقة (Security & RBAC)**:
   - نظام صلاحيات صارم (Super Admin, Admin, Manager, Customer).
   - تشفير كلمات المرور باستخدام `bcryptjs`.
   - جلسات آمنة بملفات تعريف ارتباط مشفرة (HTTP-Only Cookies & JWT).
   - حماية كاملة من SQL Injection عبر استعلامات Prisma البارامترية.
   - التحقق من كافة المدخلات في الواجهة والخلفية باستخدام مكتبة `Zod`.

5. **طبقات التجريد (Abstraction Layers)**:
   - **الدفع (Payment)**: واجهة موحدة `PaymentGatewayAdapter` جاهزة لـ:
     - الدفع عند الاستلام (COD)
     - Stripe (البطاقات الائتمانية ومدى)
     - PayPal
   - **الشحن (Shipping)**: محرك ديناميكي لحساب التكلفة وحد الشحن المجاني حسب المدينة ونوع الشحن.
   - **البريد (Email)**: واجهة جاهزة لـ Resend أو خادم SMTP مع قوالب جاهزة باللغة العربية.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Framework**: Next.js 15 (App Router, Server Actions, React 19)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Lucide React Icons
- **Database**: PostgreSQL
- **ORM**: Prisma ORM
- **State Management**: Zustand (with localStorage persistence)
- **Validation**: Zod
- **Testing**: Node.js Native Test Runner

## 🚀 دليل التشغيل المحلي (Getting Started)

### 1. المتطلبات الأساسية:
- Node.js (إصدار 20+ أو 22+)
- npm أو pnpm أو yarn
- قاعدة بيانات PostgreSQL (محلياً عبر Docker Compose أو سحابياً عبر Neon أو Supabase)

### 2. تثبيت التبعيات:
```bash
cd souq-elite
npm install
```

### 3. إعداد المتغيرات البيئية:
قم بإنشاء ملف `.env` بناءً على `.env.example`:
```bash
cp .env.example .env
```
وقم بتعديل رابط اتصال قاعدة البيانات `DATABASE_URL` إذا لزم الأمر:
```env
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/souq_elite?schema=public"
```

### 4. تشغيل قاعدة البيانات (عبر Docker Compose):
إذا كان لديك Docker مثبت، يمكنك تشغيل PostgreSQL محلياً بضغطة زر:
```bash
docker-compose up -d
```

### 5. تهجير قاعدة البيانات وتوليد Prisma Client:
```bash
npx prisma db push
```

### 6. تغذية قاعدة البيانات بالبيانات الواقعية (Seed):
```bash
npm run db:seed
```

### 7. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

## 🔑 بيانات الدخول الافتراضية (Default Credentials)

- **لوحة المشرف (Admin Dashboard)**:
  - الرابط: `http://localhost:3000/admin`
  - البريد الإلكتروني: `admin@souqelite.com`
  - كلمة المرور: `AdminSecurePassword2026!`

- **حساب عميل للتجربة (Customer)**:
  - الرابط: `http://localhost:3000/auth/login`
  - البريد الإلكتروني: `ahmed@example.com`
  - كلمة المرور: `Customer123456!`

- **كوبونات الخصم الجاهزة للاختبار في صفحة الشراء**:
  - `ELITE10` (خصم 10% للطلبات فوق 150 ر.س)
  - `WELCOME50` (خصم 50 ر.س فوري للطلبات فوق 300 ر.س)

## 📦 النشر للإنتاج (Production Deployment)

1. **قاعدة البيانات**: قم بإنشاء قاعدة بيانات PostgreSQL مجانية على [Neon.tech](https://neon.tech) أو [Supabase](https://supabase.com).
2. **الاستضافة**: اربط مستودع المشروع بمنصة [Vercel](https://vercel.com).
3. **المتغيرات البيئية**: أضف المتغيرات الموجودة في `.env.example` داخل إعدادات مشروع Vercel.
4. شغّل أمر `prisma db push` لتطبيق المخطط على قاعدة البيانات السحابية.
